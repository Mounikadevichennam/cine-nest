# CineNest Data Ingestion & Preprocessing Layer

This directory holds raw dataset ingestion templates and preprocessed TF-IDF vectors for content-based filtering.

## Data Directories
- `raw/`: TMDB catalog API responses and CSV dumps prioritized by 6 target regional languages (Telugu, Hindi, Tamil, Malayalam, Kannada, English).
- `processed/`: Processed feature matrices and TF-IDF vocabulary files for recommendation engine similarity calculations.
